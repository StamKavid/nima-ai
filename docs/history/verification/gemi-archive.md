# Read-only GEMI archive verification

2026-11-10. First slice of the user-approved offline persistence contract in
docs/sources/gemi-persistence.md. This slice adds no SQL migration, CLI command,
dependency, CI change or live request; storage follows in a separate increment.

Local `make check`: **393 tests, 97.96% combined line/branch coverage**; the new
verifier has 99% coverage. Locked dependency audit passed with the unchanged
uv.lock. Hosted final-head results are recorded in the delivery PR.

Tests failed before the verifier existed. Synthetic archives are generated by
the real collector with HTTPX MockTransport; none are production GEMI payloads.
The verifier ignores derived JSONL, rederives assertions from original bodies,
and checks body hashes/lengths including retries and error responses. It retains
transport failures without bodies, original times, 404 outcomes, leading zeros,
unknowns and exact field pointers. It reconciles every selected ID and counter.

Negative tests cover unsupported/incomplete manifests, duplicate JSON keys,
inconsistent attempts/outcomes, forged terminal states, invalid profiles, limits,
symlinks, parent traversal, nonregular files and missing/corrupt evidence. Reads
are bounded before opening another body when the aggregate budget is insufficient.
File bytes, modes and modification times remain unchanged during verification;
an absent archive is never initialized. Existing manifests do not retain response
Content-Type, so this verifier cannot revalidate that original header.

Mutation experiment: removing the body-hash comparison made the same-length
retry-body corruption test fail with DID NOT RAISE. The original guard was
restored byte-for-byte with an isolated bytecode cache before final checks.

Five-axis review: strict evidence/completeness checks; typed bounded values and
small helpers; separation from SQL/procurement projection; descriptor-relative
no-follow reads and redacted errors; sequential bounded work without broad
discovery or pairwise matching. This remains a single-owner local archive, not
a guarantee against concurrent administrator edits or later storage loss.
No live profile compatibility, company identity or collection freshness is proven.
